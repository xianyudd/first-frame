🔧 第一次配置（只做一次）

这门课的代码在老师的公开库 xianyudd/first-frame。你先复刻（fork）一份到自己账号，之后每节课都在自己的复刻里写。

  1. 在 GitHub 打开 xianyudd/first-frame，点右上角 Fork，复刻到你自己的账号。保持 Public，不要改成 Private。
  2. 在你复刻的 Actions 页启用工作流（只点这一次）：打开 https://github.com/<你>/first-frame/actions，点绿色按钮 I understand my workflows, go ahead and enable them。复刻出来的仓库默认不跑任何工作流 —— 不点这一步，后面 push 不会有任何反应，也不会报错。
  3. 把你的复刻 clone 到电脑（<你> 换成你的 GitHub 用户名）：
git clone https://github.com/<你>/first-frame.git
cd first-frame
git remote add upstream https://github.com/xianyudd/first-frame.git   # 记住老师的库，取新课用
git config commit.template .gitmessage                                # git commit 弹出中文模板
两个远程origin = 你自己的复刻（往这里 push），upstream = 老师的库（从这里取新课）。若记混，可用 git remote -v 查看。

▶️ 每节课怎么开始

配置好后，开始一门新课只需两条命令：取回老师的代码，再创建自己的练习分支。下面以第 2 课为例；第 1 课请用手册里的命令。

git fetch upstream                            # 取老师最新的课
git switch -c my-lesson-2 --no-track upstream/lesson-2   # 例：从第2课起点开自己的分支
  • 只在自己的 my-... 分支上编写、提交（commit）。
  • main 和 lesson-* 是只读起点，不修改、不推送。
  • 想备份成果：git push -u origin my-lesson-2（推送到你的复刻）。
📏 铁律写一点 → 编译 → 测试 → 通过 → 提交 → 再写下一点。一次只处理一个 ★TODO。

命令记不住？Git 闯关指南 里有速查表和「卡住了怎么办」。
